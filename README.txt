CampusOS Institute Management Demo

Open index.html in a modern browser.
No backend is required. The prototype uses mock data and client-side interactions.

Included:
- Responsive institute dashboard
- Role switcher (Director, Admin, Accounts, Faculty, HR Manager)
- Student app device preview
- Navigation, modal form, CSV export, toast notifications

Note: This is a frontend demo, not a production backend or full Figma handoff.
